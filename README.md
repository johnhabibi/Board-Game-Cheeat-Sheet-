# Board Game Rules Reference

A mobile-first web reference for Jaipur, Lost Cities, and Splendor board game rules.

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm run dev
```

## Build

```bash
pnpm run build
```

## GitHub Pages

This repo is deployed from the `gh-pages` branch.

The site is configured for:

```text
https://johnhabibi.github.io/Board-Game-Cheeat-Sheet-/
```
